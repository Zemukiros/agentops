pgvector overview

pgvector is an open-source PostgreSQL extension that adds a vector column type for storing embeddings, plus distance operators for L2 distance, inner product and cosine distance.

It supports exact nearest-neighbour search and two approximate index types: HNSW, which has better query speed and recall at the cost of slower builds and more memory, and IVFFlat, which builds faster and uses less memory.

Because vectors live in ordinary tables, similarity search can be combined with SQL filters, joins and transactions in one query.
